# 📧 Temporary Email Bot

بوت تليجرام احترافي للإيميلات المؤقتة مع مميزات متعددة.

## ✨ المميزات

- 📧 إنشاء إيميلات مؤقتة فورية
- 📥 استلام الرسائل فور وصولها
- 🔑 كشف واستخراج أكواد التحقق (OTP)
- ⏳ انتظار رسائل من مواقع محددة
- 🎨 تصميم احترافي وأزرار تفاعلية
- 👑 لوحة تحكم كاملة للمديرين

## 🚀 التثبيت

```bash
# Clone المشروع
git clone https://github.com/your-username/temp-mail-bot.git
cd temp-mail-bot

# تثبيت المكتبات
pip install -r requirements.txt

# إنشاء ملف .env
cp .env.example .env

# تشغيل البوت
python bot.py
